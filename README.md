# Honor X7 Chat

Минимальное Android-приложение:
1. При запуске открывает системные настройки специальных возможностей.
2. Пользователь вручную включает «Инверсию цветов» (если хочет).
3. После возврата приложение открывает заданное видео VK.

Видео: https://vkvideo.ru/video-222829966_456239019

## Важно
Обычное Android-приложение не может самостоятельно включать системную инверсию цветов:
для изменения защищённой системной настройки нужны привилегии, которых у обычного APK нет.
Поэтому переключатель нужно включить вручную в настройках телефона.

## Сборка APK без Android Studio
В репозитории уже есть GitHub Actions workflow:
1. Создай пустой репозиторий на GitHub.
2. Загрузи туда содержимое этой папки.
3. Открой вкладку Actions и запусти workflow `Build APK`.
4. После завершения скачай artifact `HonorX7Chat-debug-apk`.
5. Внутри будет `app-debug.apk`.

Иконка пока стандартная; свою Roblox-иконку можно добавить позже в `app/src/main/res`.
